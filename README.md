## Overview

Create already gives trains strong mechanics. Railward focuses on the visual and functional details around them: cleaner signal pieces, carriage wall variants, modular panels, and terminal hardware that fit naturally into rail-themed builds.

This mod is aimed at players who want more believable rail environments without abandoning the Create style.

## Current Content

- Modern upright signals for Create train networks
- Modern ground signals for compact trackside setups
- Train buffers for station ends, depots, and carriage
- Blue train wall blocks with multiple livery variants
- Matching wall panels for more modular carriage exteriors
- Windowed variants for shaping passenger rolling stock

## Design Direction

Railward is built around a simple goal: give Create trains stronger railway identity. The current lineup focuses on modern signal visuals and practical train body pieces that help bridges, platforms, sidings, and passenger builds look less improvised and more intentional.

As the mod grows, this foundation can support richer rail infrastructure, more rolling stock detail, and better-looking train scenes overall.

## Optional CC:Tweaked Integration

When CC:Tweaked is installed, Railward extends Create's `Create_Station`
peripheral with structured arrival predictions and live schedule information.
CC:Tweaked is not required and is not bundled with Railward. See the
[station peripheral documentation](docs/create_station_peripheral.md) for the
Lua API and examples.
